# Malazite

Malazite is a self-hosted Python programming judge.

> [!NOTE] Stack
>
> - Runtime: [Bun](https://bun.com)
> - Backend: [Fastify](https://fastify.dev)
> - Languages:
> 	- [TypeScript](https://www.typescriptlang.org) for backend and frontend scripts.
> 	- [Python](https://www.python.org) for judging system.
> - Database: [Bun:SQLite](https://bun.com/docs/runtime/sqlite)

> [!IMPORTANT]
> Malazite is still in development.
>
> No stable releases yet.
